# Luminaries

**Luminaries digital universe** — an open digital ecosystem where independent brands raise Stars and run on shared base capabilities.

The universe is larger than any single company. No one owns it exclusively.

## Roles

| Role | Meaning |
|------|---------|
| **Universe** | The open whole — brands, Stars, Constellations, and shared capabilities |
| **Steward** | [Comenix](https://www.comenix.com/) advances the ecosystem as an open platform |
| **Home Planet** | *A* operating world inside the universe (today: Comenix) — not *the* only one |
| **Independent brands** | Own domains, own capabilities, **sell their own products** |
| **Star** | A brand site raised into the universe |
| **Constellation** | How Stars are grouped for operations |

## Base capabilities

Shared foundations independent brands build on:

**Traveler** · **Chariot** · **Presentation** · **Stations** · **Security** · **Constellation**

One account across brands · market-fit checkout · one story on every screen · seats and domains · delivery with protection.
